# Work Timeline Component

Modular editorial timeline component for the Selected Works section, inspired by engineering curriculum and roadmap layouts.

## Features
- **Sticky Narrative Sidebar**: Stays anchored on the left side during desktop viewports, giving permanent context with interactive project jumping.
- **Dynamic Glowing Progress Track**: Continuous vertical timeline line with neon gradient fill that dynamically tracks the scroll position down the project cards.
- **Illuminated Nodes**: Node dots illuminate with emerald glow rings as the scroll progress passes each project.
- **Buttery Smooth Motion**: Zero 3D transform jitter, zero scroll-jacking. Native 120Hz Lenis integration with RAF throttling.
- **Responsive**: Clean stacked layout on mobile viewports with inline progress line.
